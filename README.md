# HomeSync AI

HomeSync is a roommate discovery prototype focused on finding compatible roommates quickly and safely.

## Current release
- Strict 6-digit OTP flow
- 15-question compatibility onboarding
- Dealbreakers and weighted matching
- Budget/location/commute/move-in signals
- Recent activity and verification signals
- Explainable match reasons
- Supabase questionnaire persistence

The market-informed questionnaire intentionally uses 15 questions rather than 100 to reduce onboarding friction.
